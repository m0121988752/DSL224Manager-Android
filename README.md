# DSL224Manager - Android

تطبيق أندرويد أصيل مبني بأحدث تقنيات **Kotlin** و **Jetpack Compose (Material 3 Dark Theme)** لإدارة راوترات الشبكة وراوترات الجيل الرابع (4G/LTE)، ومصمم لتتبع استهلاك الباقة بدقة وحمايتها من الاستنزاف، والتحكم الفوري في الأجهزة المتصلة.

---

## 🌟 المميزات الرئيسية

### 1. واجهة Material 3 الحديثة ونظام التبويبات الرباعي
- **تبويب الشبكة (Dashboard)**:
  - بطاقة شاملة لاستهلاك الباقة مع شريط تقدم ملون، والاستهلاك التراكمي، والمتبقي.
  - قراءة السرعات اللحظية للتحميل والرفع بالكيلوبايت/ثانية.
  - شريط بحث فوري عن الأجهزة المتصلة (بالاسم أو IP أو MAC).
  - شرائح فلترة سريعة: `الكل`، `المتصلة`، و`المحظورة`.
  - بطاقات تفاعلية للأجهزة مع إمكانية تعديل الاسم وحظر/فك حظر الجهاز.
- **تبويب الراوترات (Routers)**:
  - إدارة وحفظ أكثر من راوتر والتبديل السريع بينها.
- **تبويب الإحصائيات والسجل (Stats & Logs)**:
  - عرض مواصفات الراوتر والشبكة وسجل الأحداث الملون في الوقت الفعلي.
- **تبويب الإعدادات (Settings)**:
  - تعديل بيانات الراوتر وسعة الباقة، مع ميزة إظهار/إخفاء كلمة المرور وحفظها في التخزين المحلي الآمن (`SharedPreferences`).

### 2. تكامل متقدم مع راوترات Huawei B311-221 (Airbox / Flybox)
- **مصادقة SCRAM-SHA256**: دعم المصافحة الأمنية المخصصة لراوترات هواوي الحديثة (`challenge_login` و `authentication_login`).
- **حظر فوري وتحديث متفائل (Optimistic UI)**: يتغير مظهر الجهاز والزر في جزء من الثانية مع إرسال الطلب لـ `api/wlan/multi-macfilter-settings`.
- **حل مشاكل رموز الحماية (CSRF Tokens)**:
  - اقتطاع آخر 32 خانة من الرمز (`token.substr(32)`).
  - ربط الـ Token بالجلسة الموثقة لتفادي خطأي `125003` و `100003`.
  - إعادة المصادقة التلقائية عند انتهاء الجلسة.

### 3. دعم راوترات D-Link DSL-224
- دعم تسجيل الدخول لـ ME_1.10 Boa و Generic Realtek.
- كشط عداد الباقة وقراءة الأجهزة المتصلة.

### 4. محرك كشط الويب البديل ومُخصّص الـ No-Code (WebUI Fallback)
- كشط بيانات الراوتر والعدادات تلقائياً عبر WebView عند تعذر الـ API المباشر.
- **مُخصّص الكشط المرئي بدون كود (No-Code Scraper Builder UI)**:
  - تخصيص محدد CSS للعداد، نمط Regex، وحدة القراءة (GB/MB/Bytes)، جدول الأجهزة، وزر إعادة التشغيل.
  - قوالب سريعة جاهزة بلمسة واحدة (Presets).
- لوحة تحكم تفاعلية بأزرار صفحة الراوتر وضغط زر إعادة التشغيل (`Reboot`).
