# DSL224Manager - Android

تطبيق أندرويد أصيل (Kotlin + Jetpack Compose) لإدارة راوترات D-Link و Huawei 4G/LTE وحماية باقة الإنترنت من الاستنزاف والتحكم في الأجهزة المتصلة.

---

## 📱 المميزات
- دعم راوتر **Huawei B311-221 (Airbox / Flybox)** بمصادقة **SCRAM-SHA256** الدقيقة.
- دعم راوتر **D-Link DSL-224** (ME_1.10 Boa / Generic Realtek).
- فحص وإحصائيات الاستهلاك اللحظي والشهري وسرعات الرفع والتحميل.
- حظر وفصل الأجهزة عبر MAC Filter بضغطة زر.
- بناء سحابي تلقائي لملفات الـ APK عبر GitHub Actions.
